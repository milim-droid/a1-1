# 나만의 프롬프트 관리 프로그램

GenAI 미션에서 만든 프롬프트를 한곳에서 관리하는 **Python 콘솔 프로그램**입니다.
카테고리별 분류, 키워드 검색, 즐겨찾기를 지원하며 외부 라이브러리 없이 표준 문법만 사용합니다.
(데이터는 프로그램 실행 중에만 유지되고, 종료하면 기본 데이터로 초기화됩니다.)

## 실행 방법

Python 3.10 이상이 필요합니다.

```bash
git clone https://github.com/milim-droid/a1-1.git
cd a1-1
python prompt_manager.py      # 환경에 따라 python3
```

## 기능 목록

| 번호 | 기능 | 설명 |
|---|---|---|
| 1 | 프롬프트 추가 | 제목·내용·카테고리 입력 (빈 값이면 재입력, 카테고리는 선택 또는 직접 입력) |
| 2 | 프롬프트 목록 | 번호, 카테고리, 제목, 즐겨찾기(⭐) 표시 |
| 3 | 카테고리별 조회 | 선택한 카테고리의 프롬프트만 출력 |
| 4 | 프롬프트 검색 | 제목 또는 내용에 키워드 포함 여부 검색 (대소문자 무시) |
| 5 | 프롬프트 상세 보기 | 전체 내용 출력 |
| 6 | 즐겨찾기 관리 | 번호로 즐겨찾기 추가/해제 |
| 7 | 즐겨찾기 목록 | 즐겨찾기한 프롬프트만 출력 |
| 0 | 종료 | 프로그램 종료 |

잘못된 번호를 입력하면 안내 메시지 후 메뉴가 다시 표시되고, 각 기능이 끝나면 메뉴로 돌아옵니다.

> 번호 규칙: 검색·카테고리별 조회·즐겨찾기 목록에 표시되는 번호는 "프롬프트 목록"의 번호와 같습니다.
> 따라서 어느 화면에서 본 번호든 상세 보기(5)와 즐겨찾기 관리(6)에 그대로 입력할 수 있습니다.

## 프롬프트 카테고리

`텍스트 생성`, `이미지 생성`, `영상 생성`, `페르소나`, `자동화`, `기타`
(프롬프트 추가 시 `직접 입력`을 선택하면 새 카테고리도 사용할 수 있습니다.)

기본 데이터로 카테고리별 프롬프트 5개가 미리 등록되어 있습니다.

## 데이터 구조

```python
prompts = [
    {"title": "...", "content": "...", "category": "텍스트 생성", "favorite": True},
]
```

## 코드 구조

`show_menu()`, `add_prompt()`, `show_list()`, `show_by_category()`, `search_prompt()`,
`show_detail()`, `toggle_favorite()`, `show_favorites()` 등 기능별 함수로 분리되어 있으며,
`main()`이 메뉴 번호와 함수를 연결한 딕셔너리로 기능을 호출합니다.
